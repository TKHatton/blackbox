BLACKBOX : The Flight Recorder for AI Agents

An unerasable recording layer that any AI agent system can sit on top of. Because every decision and its reasoning is recorded,
you can rewind it, replay it under different rules, trace where a fact came from, and prove data never went where it shouldn't.
Shown here running a regulated bank complaint workflow, chosen because it is the hardest case: statutory deadlines, health data, three jurisdictions.
The same layer fits medical triage, insurance claims, loan decisions, hiring, or any agent whose decisions someone may later have to answer for.

LAYER 2 The recording layer: this is the product one way to write. no edit. no delete.
📖 The Diary
THE PERMANENT RECORD
Every event, forever, in order, with what caused what. Nothing is ever edited or removed: the code has exactly one write method and no delete, and the database itself rejects an overwrite. This is what makes everything in Layer 3 possible.
📑 The Wiki
THE WORKING MEMORY
Short, current summaries, rewritten as facts change. Agents read this, never the Diary. A system that reread its entire history to think would work in a demo and collapse in month nine.

LAYER 3 What the recording unlocks none of this works without Layer 2
🧵 Invisible Ink
Sensitive information is tagged and the tag follows it everywhere, even after the AI rewrites it in its own words. Catches a leak in a letter containing no sensitive word at all.
🧹 The Eraser
Someone asks to be forgotten. Delete the fact, and every summary built from it is rebuilt without it, even three steps downstream. The AI is never shown what it is erasing.
⏪ The Time Machine
Rewind a finished case, change one rule, and watch it play out differently. See who a policy change would have affected before you ship it.
🎭 The Stunt Double
Test a new version of an agent against genuine past cases with every action faked. Gemini judges whether it was safer or riskier, and blocks the release if it was riskier.
🛡 The Immune System
Gemini writes attacks against this system. Anything that works is kept forever and retested on every future version. Success means a rule was actually broken, not that the AI sounded flustered.
💥 The Crash Test
Break things on purpose while it runs. When two systems disagree about the same number, the fleet refuses to guess and escalates to a human instead.
🖥 The Split Screen
The live web interface, served from the same address as everything else. Every panel shows live data from the running system, never a placeholder.
